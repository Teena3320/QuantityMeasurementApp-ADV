# Quantity Measurement App – Advanced

## Overview
The Quantity Measurement App is an advanced, Test-Driven Development (TDD) based Java application used to build a scalable and extensible measurement system.

This repository demonstrates:
- Clean Code practices
- Incremental feature development using Use Cases (UC)
- Strong OOP design
- DRY principle
- Conversion and arithmetic between different quantities

## Architecture
- Java
- JUnit 5
- Feature Branch Workflow
- Each branch represents one independent Use Case (UC)

## Branch Strategy
- `main` → Stable, merged, production-ready code
- `UCx-*` → Individual feature implementation branches

## How to Run
1. Clone the repository
2. Open in IntelliJ / Eclipse
3. Run test cases using JUnit

## Learning Outcomes
- Practical TDD experience
- Building scalable measurement systems
- Designing reusable abstractions

# Quantity Measurement App – ADV (DEV Branch)

## Overview
This project implements a Quantity Measurement application using
**Test‑Driven Development (TDD)** and clean object‑oriented principles.

All active development is done in the `dev` branch.

## Purpose
The goal of this application is to:
- Design a flexible quantity measurement system
- Validate behaviors using unit tests
- Improve design incrementally through refactoring

## Development Practices
- Test Driven Development (Red → Green → Refactor)
- Clean Code principles
- Incremental changes in a single development branch
- All logic is verified through automated tests

## Branch Information
- `dev` → Active development branch
- `main` → Not finalized / not yet merged

## Testing
JUnit tests are used to define and validate the expected behavior of
the quantity measurement logic.

Running the test suite confirms:
- Correct implementation
- Safe refactoring
- No regression in behavior

## Status
Work in progress – implementation and tests evolve together
inside the `dev` branch.
